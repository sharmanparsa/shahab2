# شهاب (پروژه اندروید)

بازی داخل یک WebView تمام‌صفحه و افقی اجرا می‌شه. خود بازی فقط یک فایل است: `app/src/main/assets/index.html`.

## راه ۱: ساخت با Android Studio
1. Android Studio رو باز کن و روی Open بزن و پوشه `Shahab` رو انتخاب کن.
2. صبر کن Gradle همگام بشه.
3. از منوی Build گزینه Build APK(s) رو بزن.
4. فایل `app-debug.apk` توی `app/build/outputs/apk/debug/` ساخته می‌شه. اون رو به گوشی منتقل و نصب کن (نصب از منبع ناشناس باید فعال باشه).

## راه ۲: ساخت آنلاین با GitHub (بدون نصب چیزی)
1. یه مخزن خالی توی GitHub بساز و محتوای همین پوشه رو توش آپلود کن.
2. به تب Actions برو و workflow با نام Build APK رو اجرا کن.
3. بعد از چند دقیقه، فایل APK رو از بخش Artifacts دانلود کن.

## نکته‌ها
- فونت‌های لالزار و وزیرمتن از اینترنت می‌آن. بدون اینترنت از فونت‌های خود گوشی استفاده می‌شه و بازی کار می‌کنه.
- این APK از نوع debug است و برای تست مناسبه. برای انتشار در فروشگاه باید نسخه release با امضا بسازی.
